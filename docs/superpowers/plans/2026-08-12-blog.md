# Push Pipeline Blog — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a live, self-hosted technical blog on GitHub Pages with the first three posts of a six-part series on the push-ingest pipeline, each carrying a real interactive figure.

**Architecture:** Astro 5 static site. Posts are MDX in a typed content collection. Interactive figures are `.astro` components with plain `<script>` tags — Astro bundles them per-page, so a post with no figure ships zero JavaScript. Simulation logic lives in framework-free TypeScript modules so it can be unit-tested without a DOM. Search is a static Pagefind index built after `astro build`. GitHub Actions builds and deploys on push to `main`.

**Tech Stack:** Astro 5, MDX, TypeScript, Shiki (built into Astro), Pagefind, Vitest, GitHub Actions + GitHub Pages. **No UI framework** — no React, Vue, or Svelte.

const P = { depth: 8, drain: 9, workers: 4 };
const run = (p = P, ticks = 400, dt = 0.05) => {

  let done = 0;
  for (let i = 0; i < ticks; i++) done += step(s, p, dt);

- [ ] **Step 3: Write the implementation**

`src/scripts/pipeline-sim.ts`:

```ts
export type StageKey = 'scan' | 'io' | 'cpu' | 'db';

export interface Stage {
  name: string;
  runtime: 'tokio' | 'rayon';
  key: StageKey;
  baseRate: number;
}

export interface StageState {
  q: number;
  credit: number;
  stalled: boolean;
  busyMs: number;
  stallMs: number;
}

export interface SimParams {
  depth: number;
  drain: number;
  workers: number;
}

export const STAGES: readonly Stage[] = [
  { name: 'SCAN',   runtime: 'tokio', key: 'scan', baseRate: 26 },
  { name: 'READ',   runtime: 'tokio', key: 'io',   baseRate: 22 },
  { name: 'DECODE', runtime: 'rayon', key: 'cpu',  baseRate: 7  },
  { name: 'ENCODE', runtime: 'rayon', key: 'cpu',  baseRate: 14 },
  { name: 'COPY',   runtime: 'tokio', key: 'db',   baseRate: 9  },
];

const LAST = STAGES.length - 1;

export function initState(): StageState[] {
  return STAGES.map(() => ({ q: 0, credit: 0, stalled: false, busyMs: 0, stallMs: 0 }));
}

/** The last stage is the database; its rate is the drain slider. Rayon stages
 *  scale with worker count (4 workers is the calibration point). */
export function rateOf(i: number, p: SimParams): number {
  if (i === LAST) return p.drain;
  const s = STAGES[i];
  return s.runtime === 'rayon' ? s.baseRate * (p.workers / 4) : s.baseRate;
}

/** Advance the simulation by `dt` seconds. Returns items completed this tick.
 *  Walks downstream-first so a slot freed by the writer is visible to the
 *  encoder in the same tick — that ordering is what makes a stall recover
 *  from the back of the pipeline forwards, as it does in the real system. */
export function step(state: StageState[], p: SimParams, dt: number): number {
  let completed = 0;

  for (let i = LAST; i >= 0; i--) {
    const s = state[i];
    const isLast = i === LAST;
    const hasWork = i === 0 || state[i - 1].q > 0;
    const roomAhead = isLast || s.q < p.depth;

    if (!hasWork) {
      s.stalled = false;
      s.credit = 0;
      continue;
    }
    if (!roomAhead) {
      s.stalled = true;
      s.stallMs += dt;
      continue;
    }

    s.stalled = false;
    s.busyMs += dt;
    s.credit += rateOf(i, p) * dt;

    while (s.credit >= 1) {
      if (i > 0) {
        if (state[i - 1].q <= 0) break;
        state[i - 1].q--;
      }
      s.credit -= 1;
      if (isLast) {
        completed++;
      } else {
        s.q++;
        if (s.q >= p.depth) break;
      }
    }
  }

  return completed;
}
```
